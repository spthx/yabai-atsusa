# 最強熊谷伝説

公開URL: <https://spthx.github.io/yabai-atsusa/>

## 概要

最強熊谷伝説は、気象庁アメダスの同一観測時刻の気温データを使い、熊谷市と全国の暑さを比較するスマホ向け静的Webサイトです。派手な暑さ対決の表示と、比較の根拠になるランキングを同じ画面で確認できます。

ヘッダーの「全国916地点」はアメダス気温観測地点の規模を示す表現です。全国ランキングの集計対象は、その時点で気温データを取得できた有効観測地点のみです。

## 主な機能

- 熊谷市と、全国の観測地点または現在地に近い観測地点との暑さ対決
- 県庁所在地付近の代表アメダス地点による暑さランキング
- 県庁所在地ランキングでは1位から10位に加え、熊谷偏差値100以上の地点を表示
- 全国の有効観測地点を暑い順に並べたアメダス気温ランキング
- 全国ランキングでは、熊谷の順位・有効地点数・熊谷超え地点数を表示
- 熊谷を赤、それ以外を青で表現したオリジナルのアニメ風マスコット

## データについて

気温は、気象庁が公開するアメダスの観測値を取得して表示します。比較とランキングは、すべて同じ観測時刻の観測値から作成します。過去の最高気温ランキングではありません。

全国アメダス気温ランキングには、全国916地点のうち、気温が取得できた有効観測地点だけを含めます。欠測中の地点や気温値がない地点はランキング対象外です。

県庁所在地ランキングは、各県庁所在地付近にあらかじめ設定した代表アメダス地点を使います。県庁舎そのものの気温を示すものではありません。

## 仕組み

1. 気象庁の `latest_time.txt` から最新の観測時刻を取得します。
2. その観測時刻に対応するアメダス観測JSONと観測地点表を取得します。
3. 気温が有効な地点を暑い順に並べます。
4. 熊谷市、県庁所在地付近の代表地点、全国の有効観測地点を同一の観測データから表示します。

ブラウザだけで動作する静的サイトであり、ビルド処理や専用サーバーは必要ありません。

## 熊谷偏差値について

「熊谷偏差値」は統計学上の偏差値ではありません。熊谷の気温を100とした、本サイト独自の演出・目安です。

熊谷の気温が0℃以下、または熊谷の気温が欠測の場合は表示しません。

## 観測地点メタデータの更新

地点名・都道府県・市区町村の表示用メタデータは `js/locations.js` にあります。観測地点表を更新する必要がある場合は、次を実行して再生成します。

```bash
python scripts/build-amedas-location-metadata.py
```

生成後は、県庁所在地付近の代表地点や熊谷市の表示内容も確認してください。

## 注意事項

- 本サイトは気象庁公式サイトではありません。
- 気温の取得状況により、ランキングの有効地点数や順位は変わります。
- 本サイトは熱中症リスク、気象警報、注意報を直接判定するものではありません。健康・防災に関する判断は、気象庁や自治体などの公式情報を確認してください。
- 表示しているマスコットはすべてオリジナルであり、実在の公式キャラクターは使用していません。
