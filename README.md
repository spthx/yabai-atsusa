# 最強熊谷伝説

気象庁アメダスの同一観測時刻の気温を使い、熊谷市と全国の観測地点を比較するスマホ向け静的サイトです。

県庁所在地の観測地点を47都道府県分あらかじめ設定しており、県名・市名・気温を一覧表示します。

気温が有効な全国のアメダス観測地点も、同じ観測JSONから暑い順にすべて表示します。

各観測地点の所在地は、気象庁「地域気象観測所一覧」とWebGISが公開する都道府県フィールドを加工したの値だけを利用します。

## 仕組み

1. `latest_time.txt` から最新の観測時刻を読み取ります。
2. その時刻の観測JSONと観測地点表を取得します。
3. 熊谷市・現在地に近い観測地点・暑さランキングを、同じJSONだけから生成します。

位置情報を許可した場合は、現在地に近い有効な観測地点との比較に切り替わります。許可しない場合は、暑さランキング上位の地点を表示します。

「熊谷偏差値」は厳密な統計指標ではなく、熊谷を基準にした本サイト独自の演出・目安です。熊谷の気温が0℃以下または欠測の場合は表示しません。

## 出典

気象庁ホームページのアメダス観測データを加工して作成しています。
